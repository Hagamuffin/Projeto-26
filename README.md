# Parabellum: Disco-Elysium TTRPG interactive sheet
**Parabellum** is an unofficial, fan-made web application that uses the visuals and mechanics from the acclaimed RPG *Disco Elysium*. Its objective is to serve as a tool for the creation and management of tabletop RPGs based on the game's features.
<img width="1920" height="1083" alt="abi" src="https://github.com/user-attachments/assets/05002ec8-32cd-4b67-b535-210fa5441c5e" />

The following features were created to simulate the skills/abilities mechanics, as well as their respective checks:

## FEATURES:
### Abilities:
- Each ability (Intellect, Psyche, Physique, Motorics) can have its level selected within the range of 1 to 6.
- Skills from the same ability gain a bonus equal to its level.
- The level of an ability defines the learning cap of a skill from its category.
<img width="1918" height="158" alt="image" src="https://github.com/user-attachments/assets/3040a859-4bd9-42ab-b3b3-0877378e2cf3" />


### Health and Morale management:
- Health is determined by the sum of the Physique level and Endurance learned points, whereas Morale is determined by Psyche and Volition.
- Nosaphed and Magnesium can be used to recover Health and Morale points, respectively, following a 1:1 ratio. Their quantities are automatically decreased upon use and can be manually set by the user.
- Clicking on an empty bar consumes a healing item, while clicking on a full bar depletes it, changing the respective attribute.
<img width="688" height="175" alt="bars" src="https://github.com/user-attachments/assets/1a8fc154-5611-4071-9ac6-88a6a270f6e9" />


### Skill management and signature skill:
- Each of the 24 skills can be leveled up, which is indicated by the filled diamonds over the icons.
- A signature skill is a chosen skill that receives a +1 bonus to its learned level; moreover, the learning cap of the skills from its ability is increased by one.
<img width="501" height="171" alt="dice" src="https://github.com/user-attachments/assets/d0104a74-a87a-43db-a271-82a6e993ba60" />


### Saving progress:
- The character sheet can be saved using the "Save" button, exporting its information as a .json file.

## Next Steps:

## About the Project
This is my first project applying JavaScript, HTML, and CSS, and the biggest one I've done so far. Its main purpose was to recreate the Disco Elysium character sheet without the help of frameworks. While the application might not be the cleanest nor the most efficient, this was a project I wanted to bring to life for a while. So, if you stumbled upon it and are willing to try it out, I hope you have fun as a deranged detective!<br/>
